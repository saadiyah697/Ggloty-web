# 💄 Ggloty — Beauty Curation Platform

A modern, responsive web application for **Ggloty**, a luxury beauty infrastructure platform connecting clients with document-verified stylists and salon professionals for doorstep services.

---

## 🌟 Key Features

* **Mobile-First Luxury UI:** Engineered with custom CSS layouts, gradient overlays, and typography tailored for high-end aesthetics.
* **Interactive Media Showcase:** Integrated dynamic video reels, transformation stacks, and curated stylist lookbooks.
* **Stylist & Service Discovery:** Categorized viewing for bridal, party, grooming, and everyday beauty care.
* **Functional Contact & Booking System:** Asynchronous form handling integrated with backend submission endpoints (Web3Forms).
* **Responsive Multi-Device Layout:** Fully optimized across desktop, tablet, and mobile breakpoints.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Custom Properties & Flexbox/Grid), Vanilla JavaScript (ES6+)
* **Media & Assets:** Cloudinary CDN
* **Form Handling:** Web3Forms API
* **Icons & Fonts:** Font Awesome, Google Fonts (Cinzel / Plus Jakarta Sans)
